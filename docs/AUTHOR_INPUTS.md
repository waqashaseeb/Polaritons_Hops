# Add author matrices and missing N=5..7 models

The bundled molecular model has N=4 only. Missing rings are not generated by
copying, randomizing or padding existing rings. The current disorder realization
and model parameters must be treated as provisional.

The loader can accept a larger explicit input file. Put it under `inputs`, e.g.
`inputs/author_molecular_model.npz`, with these arrays:

| Key | Shape | Meaning |
|---|---|---|
| H_molecular_cm_inverse | (1+18*Nmax, 1+18*Nmax) | Hermitian molecular Hamiltonian, no photon |
| g_unit | (1+18*Nmax,) | Coupling factors such that H[i,photon]=g0*g_unit[i] |

Ordering is B800 at index 0, donor B850 indices 1..18, then complete external
B850 rings. Supply the authors' actual dipole normalization, sign/phase and g0
units; a different normalization changes what a numerical g0 means.

If the input is a Python variable on your machine, saving is simply:

```python
import numpy as np
np.savez_compressed(
    "inputs/author_molecular_model.npz",
    H_molecular_cm_inverse=H_molecular,
    g_unit=photon_coupling_per_unit_g0,
)
```

Copy `inputs/author_provenance_TEMPLATE.json` to
`inputs/author_provenance.json`. Fill source, ordering, realization, unit and
normalization information. Record the actual NPZ SHA256:

```bash
sha256sum inputs/author_molecular_model.npz
```

In a NEW campaign configuration set:

```json
"molecular_input": "inputs/author_molecular_model.npz",
"molecular_provenance": "inputs/author_provenance.json"
```

Then add cases with `rings` up to the number supplied. Each leading subset must
match the actual ordering/subsets used by the authors. If they used separate
disorder realizations for different N, do not use the leading-subset shortcut;
prepare separate input/configurations for those realizations.

Update protocol temperature, E0, cavity energy, frozen calibration and initial
state/preparation according to the author information. Non-300 K or non-100
cm^-1 cutoff settings trigger a fresh rank-8/rank-16 bath fit, which must be
validated again. A user-filled provenance record cannot independently prove
that a file is authentic author data.

Additional information still needed for quantitative figure comparison includes
the original initial-state selection at each coupling, actual rate-fit windows
and formula, spectral linewidth/peak processing, loss convention, realization
averaging and numerical reference curves. Adding a seven-ring matrix alone
does not verify those choices.

Paper data statement: https://arxiv.org/html/2504.02066v2#Sx5
The preprint states that supporting data can be requested from the corresponding
author. This package does not send any request or other message.
